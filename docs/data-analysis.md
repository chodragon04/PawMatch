# 공공데이터 필드 분석

입양 매칭·조건 검색에 어떤 정보를 쓸 수 있는지 확인하려고, 구조동물 API와 동물보호센터 API의
전체 데이터를 받아 필드별로 값이 채워진 비율을 정리했습니다.

- 조사일: 2026-11-03
- 대상: 유기견(`upkind=417000`) 공고 중(`state=notice`) 1,291마리 + 보호 중(`state=protect`) 1,956마리
  → 중복 제거 후 **3,247마리**, 동물보호센터 **338곳**
- 빈 문자열, `null`은 "채워지지 않음"으로 셌습니다.

### 체중 → 크기

`weight`는 `"5.6(Kg)"` 형식이지만 `"12..00(Kg)"`, `"6,3(Kg)"`, `"1.8~2.0(Kg)"`, `"2500(Kg)"`처럼
잘못 입력된 값이 약 1% 있습니다. 점 두 개는 하나로, 쉼표는 점으로, 범위는 평균으로 바꾸고,
100kg이 넘는 값은 알 수 없음으로 처리할 예정입니다.

| 크기 (현재 체중 기준) | 마릿수 | 비율 |
|---|---|---|
| 소형 (10kg 미만) | 2,330 | 72% |
| 중형 (10~25kg) | 770 | 24% |
| 대형 (25kg 이상) | 115 | 4% |
| 읽을 수 없음 (`2500(Kg)` 포함) | 31 | 1% |

주의: 60일 미만 강아지가 903마리(28%)이고 대부분 믹스견이라, **지금 체중으로는 다 자란 뒤의
크기를 알기 어렵습니다.** 매칭에서는 이 아이들의 크기를 "예측 어려움"으로 따로 표시합니다.

### 쓰기 어려운 필드

- `neuterYn`: 71%가 N, 25%가 U(미상)라 구분력이 낮습니다. 화면에 표시만 합니다.
- `vaccinationChk`(18.5%), `healthChk`(14.5%): 일부 보호소만 입력합니다. `healthChk`는 검사 항목만 있고
  결과(양성/음성)가 없어서 점수에 쓰지 않고 표시만 합니다.
- `sfeSoci`, `sfeHealth`(약 1%), 입양·자원봉사 안내(0.6%, 시흥 1곳): 거의 비어 있습니다.
- `processState`: 공고 중·보호 중 모두 `보호중`으로 와서, 공고 상태는 `noticeEdt`(공고 종료일)로 판단합니다.
